# Untitled Block

Interactive custom block built with the Orbix Block SDK

---

## 🚀 Built with the Orbix Block SDK (@orbixdocs/sdk)
- `manifest.json`: Block architecture manifest declaring capabilities & surface runtimes (`block`, `fullpage`, `sidebar_panel`).
- `src/index.tsx`: Block entry with `defineBlock` and real-time reactive state `useOrbixState`.
- `src/components/WelcomeCard.tsx`: Modern interactive task & milestone card.
- `src/types.ts`: TypeScript state interfaces.
- `src/styles.css`: Scoped block styles.
